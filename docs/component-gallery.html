Component gallery

Everything @trops/dash-react exports today, grouped by job. Each component below is the real one, rendered from dash-react's own source and Storybook stories, in Aurora dark and light. Most families come in three variants (X, X2, X3) that step down in emphasis and padding. If what you need isn't here, it's added to dash-react before a screen uses it.

Known issue fails a rule in this guide; fix tracked Use build screens with it App shell only for the app frame itself Widgets inside widgets or the Widget Builder Avoid legacy; use the named replacement Internal dash-react plumbing Proposed to be added

Previews use a test theme in the Aurora palette (neutral gray with violet and purple accents) under Aurora, not any one user's theme. Rebuild them with npm run build:gallery.
